# 신규 원거리 보스 구상: 서리의 파수꾼

상태: 초기 설계 기록. v16에서 실제 구현했으며, 최종 수치와 기능은 README.ko.md의 v16 항목 및 Frost-guide.json을 따른다. 크리스티아누는 치트 전용 실험 데이터로 보존한다.

## 외형과 기본 원칙

기본 스트레이 모델·텍스처·이동 모션과 실제 활을 사용한다. 커스텀 리소스팩 없이 식별되고, 표시 모델과 별도 투명 몹을 겹치지 않는다. 기본 크기 그대로 보스바와 이름으로 구분한다. 평소에는 걸어서 거리와 사선을 확보하며 순간이동을 반복하지 않는다. 공격은 실제 화살이며 벽과 방패로 막힌다. 즉시 피해 명령으로 화살을 대체하지 않는다. 근접 피해도 정상적으로 들어간다.

## 전장과 시작

오버월드 눈 덮인 산·설원에 35×35 규모의 폐망루를 새 청크에 자연 생성한다. 석재 벽·눈·가문비나무·쇠창살 등 기본 블록만 사용한다. 평평한 중앙과 양측 경사 통로를 연결하고, 꼭대기는 4블록 높이까지만 올려 활 조준을 막지 않는다. 전체 바닥의 약 1/4만 얼음으로 두고 안전한 일반 바닥 경로를 남긴다.

엄폐 기둥 4개, 낮은 벽 2개를 배치한다. 기둥 사이에 이동할 수 있는 틈을 남기고 어느 위치에서도 다른 엄폐물로 이동할 경로가 있도록 한다. 플레이어를 방 안에 가두는 벽은 없다. 파괴한 일반 엄폐물은 전투 중 강제로 복원하지 않는다.

망루 중앙의 봉인 표적을 화살로 맞히면 시작한다. 표적은 기본 타깃 블록과 명확한 안내로 표시한다. 치트 없이 시작 가능하며, 도전자가 전멸하거나 전장 밖에 10초 동안 머무르면 전투를 초기화한다. 무인 상태의 공격과 아이템 보상은 없다.

## 기준 수치

수치는 구현 시 시험으로 조정할 목표다. 체력은 1인 360, 추가 인원마다 180, 최대 900. 보통 활·석궁과 철 장비로 도전 가능하게 한다. 피해는 방어구 적용 전 기준으로 일반 화살 약 2~3하트, 대형 사격 약 4하트를 목표로 하되 실제 화살 속도·기본 피해를 시험해 맞춘다. 방패는 유효하다. 즉사, 장비 도난, 영구 지형 파괴, 긴 조작 불능은 없다.

기본 기술 사이 대기는 1초, 후반 0.6초. 예고와 공격 동작, 장전 반격 시간은 이 대기와 별도다. 모든 강한 공격에는 소리와 방향·범위를 알 수 있는 기본 파티클을 먼저 보여준다. 원거리 공격은 시선이 차단되면 현재 벽 뒤 플레이어에게 강제 피해를 주지 않는다.

## 공격과 대응

| 기술 | 예고·발동 | 플레이어 대응·반격 |
|---|---|---|
| 서리 화살 | 기본 활 사격. 맞으면 2초 둔화 I, 지속시간만 갱신 | 옆으로 이동하거나 방패·엄폐물 사용 |
| 갈라지는 사선 | 0.8초 동안 활을 들고 조준 방향을 알린 뒤 5발을 부채꼴로 발사 | 예고된 틈 또는 엄폐물로 이동. 이후 1.2초 장전 중 반격 |
| 잔상 조준 | 발밑 눈 파티클과 조준 소리. 0.7초 후 표시 당시 위치로 3연사 | 표시를 보고 이동. 이후 플레이어 이동을 다시 추적하지 않음 |
| 높은 포물선 | 위를 향해 활을 들고 지정된 3곳에 착탄 예고, 1.2초 후 실제 화살 낙하 | 표시 밖으로 이동. 천장 있는 엄폐는 화살 차단 |
| 망루 이동 | 짧은 호각 후 경사 통로를 따라 다른 사격점으로 걸어감 | 이동 중 공격 가능. 경로가 막히면 사격점 이동을 취소하고 가까운 안전 지점 사용 |
| 마지막 장전 | 체력 35% 이하, 일반 사격 두 번 뒤 1초 예고하고 강한 직선 화살 1발 | 방패나 벽으로 차단. 이후 1.5초 정지 장전이 큰 반격 기회 |

모든 기술마다 서로 다른 위치로 강제 이동시키지 않는다. 최대 두 공격을 이어 사용한 뒤 장전 시간을 준다. 장전 중에는 별도 피해 배율을 붙이기보다 보스가 사격을 멈춰 명확한 공격 기회를 제공한다. 기본 스트레이의 활 사용 동작과 걷기를 활용하며, 없는 전용 애니메이션을 있는 것처럼 전제하지 않는다.

## 단계

- 100~70%: 일반 사격·부채꼴·잔상 조준으로 규칙을 익힌다.
- 70~35%: 포물선과 사격점 이동을 추가한다. 부채꼴과 잔상 조준의 예고를 겹치지 않는다.
- 35% 이하: 대기를 줄이고 마지막 장전을 추가한다. 반격 시간은 줄이지 않는다. 후반 강화는 증원 폭증이나 즉사 대신 사격 조합으로 만든다.

보조 몹은 체력 70%, 35% 진입 시 기본 스트레이 1마리씩만 소환한다. 동시 최대 2마리, 주기적인 무제한 증원은 없다. 보조 몹을 처치하면 가장 가까운 참여자에게 4초 속도 I을 주어 엄폐 이동에 도움이 된다. 처치 없이 클리어하는 도전도 가능하다.

## 보상과 도전과제

보상은 보통 화살·얼음·에메랄드와 이름 붙인 기본 활이다. 전용 장신구 시스템이나 새 투사체 텍스처를 요구하지 않는다. 활은 기본 인챈트 조합을 쓰고 최종 인챈트 수치는 밸런스 시험 후 정한다.

일반 과제: 망루 발견 / 최초 처치 / 장전 중 적중 / 보조 몹 처치. 하드 과제: 보조 몹 미처치 승리 / 방패 없이 승리 / 3분 이내 승리 / 보스 화살 무피해 승리. 횟수는 전투마다 초기화하고, 승리는 끝까지 참여한 생존자만 받는다. 보스 화살 무피해는 보스와 보조 몹의 화살을 명시적으로 추적하며 환경 피해는 조건에 포함하지 않는다.

## 구현·검증 기준

기본 활 AI와 패턴 사격이 동시에 발사되지 않도록 한쪽만 사격하도록 제어한다. 평시 이동·사선 판단에는 바닐라 AI를 활용하고, 패턴 동안의 조준·화살 생성·장전은 데이터팩에서 제어한다. 화살의 실제 충돌과 소유자 추적, 방패 방어, 엄폐, 보조 몹 효과, 중단 시 정리를 연결된 클라이언트로 검증한다.

자연 생성과 봉인 표적 시작을 별도로 검사한다. 지형이 급격한 위치에 경기장이 땅속에 묻히거나 떠 있으면 배치 조건을 조정한다. 기본 스트레이 크기의 피격 범위 안에서 몸통을 맞힐 수 있는지, 활 사격 모션이 보이는지, 경로가 막혀도 보스가 정지한 채 전투를 무기한 멈추지 않는지를 출시 조건으로 삼는다.

## v19 최종 수치

24방향 3회 사격, 반경 10의 24발 수렴, 0.6초 예고, 0.6~0.8초 장전. 5초마다 공격 종료 후 안전 지점으로 순간이동. 동결 화살 3회 조준 사격은 2초 스턴 후 전투 종료까지 구속 II를 남긴다. 60초 경과 시 모든 참가자가 구속 II를 받는다. 사망·이탈·전투 종료 시 효과를 정리한다. 자세한 수치와 적용 조건은 README v19와 Frost-guide.json을 따른다.

## v20 외벽 사격

보스 중심 사방 사격을 경기장 네 외곽 벽의 고정 발사 지점으로 교체한다. 간격 4블록, 32/28/32발의 세 파동으로 총 92발을 안쪽으로 발사한다. 막힌 관중석 구간은 첫 열린 지점으로 이동해 발사한다. 자기 화살 피해는 투구의 전용 피해 면역 인챈트로 무효화하며 플레이어 공격은 유지한다.
