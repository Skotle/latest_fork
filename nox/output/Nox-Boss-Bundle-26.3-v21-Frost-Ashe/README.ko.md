# 녹스 v2 Fast — 공격 예고·대기 2초 이하

Minecraft Java **26.3**용 독립 데이터팩입니다. IDA 데이터팩이나 플러그인에 의존하지 않습니다. 합본 리소스팩은 기존 IDA 통합 리소스팩의 자산을 보존하고 녹스 자산을 추가합니다. 원본 ZIP은 수정하지 않습니다.

## Fast 변경점

단일 공격 예고·폭발 지연·구역 전환·회복과 추가 대기를 모두 2초 이내로 조정했습니다. 일반 공격은 회복+대기 합계 1.5초, 돌진은 1.75초, 벽 충돌·봉인 해제·일식 종료는 합계 2초입니다. 3연속 충격파와 일식의 전체 패턴 길이는 여러 짧은 공격 구간의 합이며, 한 번의 대기 시간이 아닙니다. 전투 전 진입 유예와 플레이어가 직접 푸는 봉인종 퍼즐에는 적용하지 않습니다.

## v2 변경점

- 몸통·머리·양팔·왼손·종팔·양다리·심장·고리의 **10개 관절**을 따로 움직입니다. 대기 호흡, 교차 보행, 공격 준비, 타격, 회복, 돌진, 휘청임, 의식의 8종 동작과 각 16개 자세를 제공합니다. 초당 10회 갱신하고 2틱 보간합니다.
- 접근 속도를 높이고 근거리 옆걸음, 방향이 바뀌는 2연격, 직선 돌진, 확장 충격파를 추가했습니다. 공격 사이 대기 시간을 줄였습니다.
- 돌진 직후, 벽 충돌, 봉인 해제, 개기일식 종료 시 심장 노출 동안 **실제 감소한 체력에 피해 50%를 추가**합니다.
- 새 오버월드 청크의 랜덤한 지하에 관측소가 자연 생성됩니다. 여러 관측소를 발견할 수 있습니다. 전투는 한 월드에서 한 번에 하나 진행합니다.

## 설치·업데이트

1. 월드를 백업하고 서버·월드를 완전히 종료합니다.
2. `Nox-Standalone-Datapack-26.3.zip`을 월드 `datapacks`에 넣습니다. v1 파일을 교체하고 중복 활성화하지 않습니다. IDA 데이터팩은 함께 사용할 수 있습니다.
3. `Integrated-Resources-with-Nox-26.3.zip`을 클라이언트 `resourcepacks`에 넣고 기존 통합 리소스팩 대신 적용합니다. 교체 후 F3+T 또는 재접속으로 다시 읽습니다. 기존 리소스팩을 유지하려면 출력 폴더의 `Nox-Additional-Resources-26.3.zip`을 가장 위에 추가할 수도 있습니다.
4. 서버·월드를 다시 시작합니다. **새 월드 생성 등록은 완전 재시작 후 사용하세요. 기존 청크에는 구조물이 소급 생성되지 않습니다.** 새 지역을 탐험하거나 새 시험 월드를 사용합니다.
5. 서버에서 리소스팩을 배포한다면 URL과 SHA-1도 갱신합니다. `release-hashes.json`에 배포용 SHA-1이 있습니다. 리소스팩이 없으면 보스 본체가 보이지 않습니다.

v1의 수동 경기장은 지형이 자동 갱신되지 않습니다. 새 관측소를 찾거나, 전투가 없을 때 이전 관측소에서 `admin/unregister`로 전용 엔티티를 제거하고 수동 재설치하세요. 지형 복구는 월드 백업을 사용합니다.

## 지하 관측소

```mcfunction
/locate structure eclipse_nox:observatory
```

월드 시드에 따라 `random_spread`로 배치됩니다. 간격은 48청크(768블록), 후보 최소 분리는 24청크이며 정확히 768블록마다 반드시 하나 생기는 의미는 아닙니다. 오버월드 바이옴에만 생성되며, 중앙 발 위치는 **Y=-45~-21**, 천장은 그보다 17블록 위로 모두 지하에 있습니다. `/locate` 검색 좌표는 정확한 중앙 좌표·전투장 Y와 다를 수 있습니다.

본당은 지름 49블록이고 외벽·천장·조명과 네 방향 진입 회랑을 갖췄습니다. 회랑이 동굴에 접하면 탐험 중 발견할 수 있습니다. 주변이 막혔다면 돌을 파고 들어가야 합니다. 지상 탑과 자동 연결 갱도는 포함하지 않습니다. 템플릿은 본당과 회랑만 지형을 바꾸며 밖의 지형을 보존합니다. 구조물 범위의 일반 적대 몬스터 자연 스폰은 억제합니다.

가까이 접근하면 구조물 마커가 봉인종·소환 장치·문양을 초기화하며 반복 방문으로 중복 생성되지 않습니다. 소환 장치는 중앙의 남쪽(+Z) 29블록 지점입니다. 네 방향 회랑이 대칭이라 랜덤 회전에도 봉인종 방향은 유지됩니다.

## 전투

참가자가 중앙 또는 준비 회랑에 모인 뒤 소환 장치를 **우클릭**합니다. 서바이벌·모험 모드만 등록하며 Y+8 관측 발코니의 플레이어는 제외합니다. 첫 15초는 입구가 열려 있고 이후 네 입구가 닫힙니다. 다른 관측소에서 전투 중이면 새 전투를 시작할 수 없습니다.

관리자는 관측소에서 `/function eclipse_nox:admin/start`, 어디서든 `/function eclipse_nox:admin/abort`를 사용할 수 있습니다. 시작 후 사망·접속 종료한 참가자와 새 플레이어는 그 전투에 합류할 수 없습니다. 모든 참가자가 경기장에 5초 동안 없거나 전투가 6분을 넘으면 중단합니다. 활성 경기장 청크가 언로드되어 앵커가 사라져도 전투 잠금을 해제하고, 나중에 로드되면 입구·남은 전투 엔티티를 정리합니다.

체력은 1인 600, 2인 900, 3인 1200, 4인 이상 1500으로 시작 시 확정합니다. 공격은 기본 순환과 거리로 선택하며 멀리 떨어지면 돌진을 우선하되 바로 연속 돌진하지 않습니다.

| 패턴 | 예고·대응 |
|---|---|
| 종 2연격 | 첫 1.5초 예고 후 타격, 방향을 70도 바꿔 1초 예고와 두 번째 타격. 두 번 피한 뒤 1.25초 회복 공략 |
| 시계추 돌진 | 1.2초 직선 예고 후 약 14.4블록 전진. 옆으로 피하기. 이후 1.5초, 벽 앞 충돌 시 1.75초 심장 노출 |
| 충격파 | 일반은 반경 3~6, 마지막 단계는 3~6 → 7~10 → 11~14로 1.2초 간격 확장. 불꽃 고리 안쪽으로 이동 |
| 잔향 | 현재 위치 기록 후 1.5초 폭발. 표식은 플레이어를 따라가지 않음 |
| 봉인종 — 체력 65% | 보호막, 2초마다 잔향. 북쪽 1 → 동쪽 3 → 서쪽 2 순서로 우클릭. 성공 시 1.75초 심장 노출. 같은 종 연속 클릭은 1.5초 뒤 과부하 |
| 개기일식 — 체력 30% | 7초 동안 1초마다 회전하는 부채꼴 안전 구역. 청록색 현재 구역에서 흰색 다음 구역으로 이동. 종 반경 3은 회전 후 0.5초 피난처. 종료 후 1.75초 심장 노출 |

2연격은 타격당 원시 피해 6, 돌진은 7의 `mob_attack`입니다. 충격파·일식은 마법 피해 4, 잔향·과부하는 마법 피해 6입니다. 2 HP가 하트 하나이며 장비·효과·플러그인에 따라 실제 피해가 달라집니다. 같은 타격의 중첩 표식은 한 번만 피해를 줍니다.

심장 노출 보너스는 노출 중 보스 체력 감소를 다음 서버 틱에 측정하고 추가 50%를 차감합니다. 몸통의 모든 피격에 적용하며 심장만의 별도 히트박스는 없습니다. 피격은 투명한 ravager가 담당합니다. 몸통을 공격하세요. 돌출된 종·고리·팔다리 끝에는 별도 판정이 없습니다.

처치 보상은 접속 중이며 사망·접속 종료 기록이 없는 참가자에게 일식의 심장 1개, 다이아몬드 4개, 경험치 500입니다. 심장은 전용 외형의 처치 증표입니다. 처치·중단·리로드 후 장치와 구조물은 남아 다시 도전할 수 있습니다.

## 수동 시험·제약

```mcfunction
/execute in minecraft:overworld positioned 0 100 0 run function eclipse_nox:admin/install
/function eclipse_nox:admin/unregister
```

수동 설치는 지정 위치를 중앙 발 위치로 삼고 X/Z ±34, Y -2~17 범위의 본당·회랑 블록을 **덮어씁니다**. 백업한 시험 월드에서 사용하세요. `unregister`는 전투가 없을 때 주변 40블록 이내 가장 가까운 관측소의 전용 엔티티를 제거합니다. 구조물 블록과 생성 기록은 남으며 원래 지형으로 복원하지 않습니다.

건축 제한, 플레이어 순간이동 제한, 리소스팩 수락 감지, 관측소 간 동시 전투는 포함하지 않습니다. 건축 제한이 필요하면 모험 모드나 서버 구역 보호를 사용하세요. 전용 음향 이벤트는 바닐라 종·비콘·워든 소리를 재사용합니다.

## 검증·재현

```powershell
python nox/build.py
python nox/verify_engine.py
python nox/verify_worldgen.py
python nox/preview.py
python nox/release.py
```

빌드는 Python 표준 라이브러리, 미리보기는 Pillow를 사용합니다. 엔진 검사는 기존 작업 폴더의 공식 Minecraft 26.3 JAR·Java 25와 시험용 네트워크 에이전트를 사용하고 별도 월드를 만듭니다. 에이전트는 이 PC의 네트워크 리스너 문제 우회용이며 배포물에 포함되지 않습니다.

- `engine-validation.json`: 함수·128개 관절 자세, 양다리 반대 회전, 돌진 거리·벽 정지, 2연격, 노출 피해 배율, 페이즈·봉인종·표식·32개 안전 구역 경계, 리로드·처치·중단 정리.
- `worldgen-validation.json`: 새 일반 월드에서 자연 생성 검색, 지하 높이·바닥·천장·공간, 여러 관측소 등록.
- `static-validation.json`: 함수·모델 참조와 기존 리소스 보존.
- `timing-profile.json`: 공격별 예고·지연·회복과 추가 대기 합계를 틱 단위로 기록. 20틱이 1초입니다.
- `Nox-Motion-Preview.gif`: 실제 생성 모델·자세 데이터의 소프트웨어 렌더링. **게임 화면이 아닙니다.**

실제 접속 플레이어의 우클릭·피해·재접속 차단·파티 밸런스와 클라이언트 렌더링은 아직 검증하지 않았습니다. 자연 생성 검사는 하나의 일반 월드 시드에서 진행했습니다. 시험 월드에서 먼저 플레이하세요.


## v3 — 심판과 하위 몹
- 일반 공격 예고: 첫 연격/잔향/단일 고리 1초, 두 번째 연격 0.6초, 돌진 0.8초. 일반 회복+대기 0.7초, 돌진 0.9초, 노출 1.1초.
- 체력 30% 이하: 최후의 심판. 2초 경고 동안 중앙 금빛 원(반경 4블록)으로 이동. 원 밖의 살아 있는 참가자는 방어를 무시하는 즉사 피해를 받습니다. 일반 공격과 심판 예고는 겹치지 않습니다. 심판은 약 8초 간격으로 준비되며 진행 중인 공격이 끝난 뒤 시작됩니다.
- 보스 등장 시 잔향 시종(체력 24, 공격력 3)과 종의 파수꾼(체력 36, 공격력 5) 동반 등장. 각 페이즈 전환 및 5초마다 2마리 증원, 최대 6마리. 각각 전용 픽셀 텍스처 및 입체 모델. 투명 허스크의 근접 AI와 탑승 표시 모델을 사용합니다.
- 보스 전투 종료/중단/리로드 시 하위 몹 제거. 처치된 하위 몹의 표시 모델도 제거합니다.
- 기존 오버월드 지하 자연 생성 및 원본 리소스팩 확장 방식 유지. 기존 패키지를 교체하고 서버 재시작.
- 실제 클라이언트 모델 표시 및 플레이어 즉사/회피 체감은 플레이 테스트가 필요합니다.


## 원거리 피해 및 벽 충돌 카운터 조정
- 충격파·일식 일반 피해: 4 → 1. 잔향·봉인종 과부하: 6 → 1.5. 기존의 ¼ 피해. 근접/돌진/즉사 심판은 유지.
- 돌진이 벽 또는 경기장 경계에 막히면 2초간 완전히 멈추고 심장을 노출합니다. 이 시간 동안 녹스에게 주는 피해는 2배. 충돌 없는 돌진은 일반 회복만 합니다. 심판도 카운터 시간이 끝날 때까지 기다립니다.


## v4 하위 몹 개선 (이전 하위 몹 설정 대체)
- 고정된 단일 모델을 6개 관절 모델로 교체. 실제 이동량에 따라 걷기/대기 전환, 근접 시 팔 휘두르기. 몸통·머리·양팔·양다리와 보간 적용.
- 최대 2마리. 페이즈 전환 증원 제거. 모두 처치된 뒤 18초가 지나면 한 쌍 등장.
- 시종을 참가자가 처치하면 처치한 참가자 주변 반경 8블록 참가자에게 즉시 회복 + 5초 재생·신속.
- 파수꾼을 참가자가 처치하면 반경 8블록에 6초 저항·흡수. 다음 공격과 회복이 끝나면 녹스가 2초간 노출되어 받는 피해 2배. 즉사기 회피 조건은 유지.
- 사망 보상은 각 몹당 한 번. 환경 사망·전투 중단·리로드 정리는 보상을 주지 않습니다.
- 데이터팩과 통합 리소스팩을 모두 교체하고 서버 재시작. 기존 보스 전투 중 교체는 권장하지 않습니다.


## 하위 몹 몸통 타격 수정

- 파티클은 발사구에 표시됩니다. 관중석 내부처럼 막힌 위치는 안쪽의 첫 열린 지점으로 당겨 실제 화살이 즉시 벽에 박히지 않게 합니다. 구조물이나 지형 블록을 파괴하지 않습니다.
- 보스의 보호 투구에 전용 피해 면역 인챈트를 적용합니다. 공격 주체가 이 보스인 피해만 무효화합니다. 되돌아온 자기 화살과 수렴 화살은 보스 체력을 깎지 않으며, 플레이어 화살·근접 공격은 정상적으로 적용됩니다. 인챈트는 일반 획득 목록에 넣지 않습니다.
- 수렴 화살, 순간이동, 스턴 및 전투 중 구속은 v19 설정을 유지합니다. 발사 지점 표식과 화살은 전투 종료 때 정리됩니다.

기존 데이터팩을 교체하고 `/reload` 후 다시 시작하세요. 기존 경기장에서도 다음 소환 시 발사 지점이 구성됩니다. 리소스팩 변경은 없습니다. 실제 서버 플레이어 및 물리 화살 검사 결과를 함께 제공합니다. 연결된 클라이언트의 화면과 체감 난이도는 별도 플레이 테스트가 필요합니다.

## v21 애쉬 스킬을 참고한 전투 재조정

이 절이 앞선 서리 보스 수치보다 우선합니다. 요청한 나무위키 본문은 접근이 차단되어 라이엇 공식 애쉬 페이지와 Data Dragon 16.20.1 한국어 스킬 데이터를 확인했습니다. 그대로 복제하지 않고 마인크래프트의 엄폐·방패·실제 화살 물리에 맞춰 조정했습니다.

참고: https://www.leagueoflegends.com/ko-kr/champions/ashe/ 및 https://ddragon.leagueoflegends.com/cdn/16.20.1/data/ko_KR/champion/Ashe.json

- 체력: 1인 900, 2인 1350, 3인 이상 1800. 종전보다 25% 감소합니다.
- 서리 화살: 일반 사격은 짧은 구속 I 1초만 부여합니다. 피해 계수를 2.6에서 1.6, 비행 속도를 2.6에서 2.0으로 낮춥니다. 일반 사격·연사·일제 사격·외벽 화살은 방패로 막을 수 있습니다.
- 궁사의 집중: 기본 사격과 일제 사격으로 집중을 4회 쌓으면 소비하여 0.3초 간격으로 약한 화살 5발을 연사합니다. 피해 계수 0.9이며 기절이나 폭발은 없습니다.
- 일제 사격: 조준 방향을 고정하고 1초 예고 후 72도 부채꼴로 9발 발사합니다. 부채꼴 밖으로 이동하거나 기둥·방패로 대응할 수 있습니다.
- 매 날리기: 피해 없이 매의 혼을 나타내는 파티클이 날아가 근처 참가자를 3초 발광시킵니다. 정찰 중 공격을 중첩하지 않습니다.
- 마법의 수정화살: 고정된 푸른 사선을 1.6초 예고하고 한 발만 쏩니다. 피해 계수 2.5, 발사 후 유도·추적은 없습니다. 이 화살만 방패를 관통합니다. 처음 맞은 참가자에서 화살을 정리하며 근처 참가자에게는 짧은 둔화만 부여합니다. 원작의 광역 추가 피해는 넣지 않았습니다.
- 수정화살 기절: 보스와의 거리 8블록 이하 0.5초, 18블록 이하 1초, 그보다 멀면 1.5초. 실명과 영구 구속을 제거했고 기절 종료 즉시 이동을 회복합니다. 피격 후 4초 동안 추가 기절을 막습니다. 수정화살 이후 최소 2.5초의 장전 시간을 제공합니다.
- 외벽 사격: 마주 보는 두 벽만 표시하고 1초 후 16발을 한 번 발사합니다. 다음 외벽 사격에서는 다른 두 벽을 사용합니다. 발사구 간격 4블록과 고정 위치, 자기 화살 피해 면역은 유지합니다.
- 전투 흐름: 일제 사격 → 기본 사격 → 일제 사격 → 기본 사격 → 집중 연사 → 정찰 → 일제 사격 → 외벽 사격 → 수정화살. 집중 부족 시 해당 연사 차례는 기본 사격으로 대체합니다. 기술별 장전 1~2.5초, 추가 대기 1.6/1.2/1초입니다.
- 순간이동은 약 10초마다, 공격과 장전이 끝난 뒤에 실행합니다. 70% 단계에서 보조 스트레이 한 마리만 소환하며 35% 단계에서 추가하지 않습니다. 보조 화살 피해도 낮춥니다.
