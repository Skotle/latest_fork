# 연결 대양 구성

기준: 대륙에 둘러싸인 내해는 금지하고 작은 호수는 허용합니다.

기존의 무작위 대륙 노이즈를 그대로 쓰지 않고, 각각 중심에서 해안까지 육지가 이어지는 별 모양 영역으로 대륙성 필드를 구성합니다. 해안 반경은 방향과 셀 중심, 시드 노이즈에 따라 달라집니다. 같은 방향에서 해안까지의 선분 중간에 해양 구멍을 만들지 않습니다.

대륙 중심 간격은 3,600블록, 해양 경계 반경은 870~1,230블록입니다. 인접 대륙의 최대 반경 사이에도 최소 1,140블록의 여유가 남습니다. 따라서 이 대륙성 필드에서 바다는 대륙 바깥으로 이어지며 육지 고리에 갇힌 해양 영역이 생기지 않습니다. 강과 작은 호수 생성은 별도로 제거하지 않습니다.

이 방식은 자유로운 노이즈 대륙보다 중심 배치가 규칙적이고 해안 형태에 제약이 있습니다. 기존 원작의 주변 섬 생성과 시작 섬 합성은 최종 필드에 사용하지 않습니다. 기존 슬라이더도 새 생성식에 적용되지 않으므로 ZIP에서 제외했습니다. 설정은 `build_connected.py`의 `fields()`에서 조정하며 반경 상한이 셀 반간격보다 작은 조건을 검사합니다.

`Continents-Connected-Ocean-26.3.zip` 하나만 설치합니다. 이전 프리셋 ZIP 및 같은 대륙성 함수를 덮어쓰는 팩은 함께 넣지 않습니다. 새 월드에서 사용하는 것이 기준입니다. 기존 청크의 고립 수역은 바뀌지 않습니다.

검증 범위: 대륙성 필드의 구조와 표본 연결성, JSON 파싱, ZIP 무결성. 공식 26.3 밀도 함수 코덱과 노이즈 계산기로 12개 시드에서 각각 321×321점을 32블록 간격으로 측정했습니다. 모든 시드에서 상하좌우 기준 해양 성분 1개, 고립 해양 성분 0개였습니다. 기록은 `output/connected-engine-validation.json`에 있습니다.

전체 데이터팩의 서버 로딩과 실제 블록·바이옴 지형 검증은 아직 수행하지 않았습니다. 이 결과를 모든 실제 수면의 연결성을 검증한 배포판으로 간주하지 않습니다. 호수와 내해의 실제 크기 판정도 별도 게임 내 확인이 필요합니다.

재현: `python continents/build_connected.py` 후 `python continents/verify_connected.py`. 검증 도구는 현재 작업 공간의 `.tools`에 있는 공식 26.3 서버 번들, 라이브러리와 JDK 25를 사용합니다.
