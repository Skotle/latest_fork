# IDA 26.3 구조물 보스판

## 설치

월드를 백업한 뒤 기존 IDA 데이터팩 ZIP을 `IDA-Vanilla-26.3-Bosses.zip`으로 교체하고 `/reload`를 실행하세요. 보스판에는 기존 변환 데이터팩 전체가 포함되어 있으므로 두 ZIP을 함께 활성화하지 마세요. 새 월드 또는 아직 생성하지 않은 청크에서 구조물이 생성됩니다.

제공된 `Integrated-Resource-Pack-with-Ancient-Artifacts-2.zip`은 수정 없이 그대로 사용합니다. 모드나 플러그인은 필요하지 않습니다. 보스 외형은 바닐라 몹, 이름, 장비, 크기, 입자로 표현합니다.

## 전투 규칙

- 26종 중 22종에 보스를 추가했습니다. 여관, 상인 야영지, 등대, 소원의 우물은 휴식 장소로 유지합니다.
- 서바이벌/어드벤처 플레이어가 구조물의 게임상 경계에 들어오면 주변의 바닥과 공간을 검사해 보스를 소환합니다. 고정된 중앙 방에 배치하는 방식이 아니며, 가까운 지상 공간이 없으면 소환을 다시 시도합니다.
- 보스마다 두 가지 특수 공격을 번갈아 사용합니다. 일반 스킬은 2초, 태양왕의 낙인은 3초 전 경고하고 표식을 0.25초마다 반복 표시합니다. 특수 공격 범위를 최대 3블록으로 줄이고 피해와 상태 효과를 완화했습니다. 태양의 낙인은 반경 2.5블록, 피해 4입니다. 기본 몹의 공격도 함께 사용합니다.
- 기본 근접 피해를 약 25% 줄이고 특수 공격 간격을 기존보다 3초 늘렸습니다. 체력 50% 이하에서 강화되면 공격 간격이 1초 줄어듭니다. 추가 이동 속도 강화는 제거했습니다. 일부 보스는 강화 상태에서 부하를 소환합니다.
- 시작 시 반경 96블록 내 참여 인원에 따라 추가 1명당 체력이 25% 증가합니다. 최대 4명, 기본 체력의 175%까지 반영합니다.
- 같은 종류의 보스 구역을 반경 384블록에서 중복 생성하지 않습니다. 매우 가까운 동일 종류 구조물은 하나의 구역으로 취급될 수 있습니다.
- 보스존은 최초 소환 위치를 중심으로 반경 24블록의 구역입니다(높이도 거리 계산에 포함). 보스와 부하 모두 매 틱 확인하며 경계를 벗어나면 중앙으로 복귀하고 이동 관성을 제거합니다. 보스 복귀 시 진행 중 특수 공격도 취소합니다. 재소환해도 존의 중심은 바뀌지 않습니다. 전투 중 지면 높이의 경계에는 흰 입자 표식을 표시합니다. 특수 공격의 조준 대상은 존 안의 플레이어로 제한합니다. 반경 128블록에 참여자가 60초 동안 없으면 보상 없이 전투를 초기화합니다.
- 처치 시 고유 장비 1개, 에메랄드, 경험치 병을 떨어뜨립니다. 주변 참여자는 최초 처치 발전 과제와 경험치를 받습니다.
- 비단 여왕, 역병 수용소의 원장, 공허의 정복자 3종만 보상 장비의 기존 인챈트를 각각 정상 획득 최대 레벨 +1로 설정합니다. 커스텀 인챈트도 해당 데이터팩 최대 레벨 +1을 적용합니다. 나머지 19종의 보상, 일반 책·인챈트·던전 상자의 최대치는 유지합니다. 이전에 획득한 장비는 자동 변경되지 않습니다.
- 처치 후 구역이 로드된 상태로 30분이 지나면 재도전할 수 있습니다. 부하는 최대 4마리이며 90초 후 정리됩니다.
- 평화로움에서는 자동 소환하지 않고 진행 중 전투를 초기화합니다. 공격 효과는 블록을 파괴하거나 불을 놓지 않습니다.

## 관리자 명령

현재 위치에 시험 소환: `/function dungeons_arise:boss/admin/spawn/typhon`

다른 보스는 마지막 `typhon`을 표의 구조물 ID로 바꾸세요. 시험 소환은 중복 방지를 우회하므로 반복 실행 시 보스가 여러 마리 생깁니다.

명령어로 소환한 보스는 종료·처치 후 자동 재소환하지 않습니다. 기존 버전에서 만든 시험 구역을 제거하려면 `/function dungeons_arise:boss/admin/remove_nearby`를 사용하세요. 주변 128블록의 전투를 종료하고 구역 기록을 지웁니다. 실제 구조물 안에서는 자연 진입 감지로 새 구역이 생성될 수 있습니다.

주변 전투를 보상 없이 종료: `/function dungeons_arise:boss/admin/abort_nearby`

주변 전투와 재도전 대기 초기화: `/function dungeons_arise:boss/admin/reset_nearby`

자동 소환 끄기/켜기: `/scoreboard players set #enabled ida.cfg 0` / `/scoreboard players set #enabled ida.cfg 1`

재도전 대기 설정(로드된 초): `/scoreboard players set #respawn ida.cfg 1800`

이탈 초기화 대기 설정(초): `/scoreboard players set #abandon ida.cfg 60`

## 검증 범위

실제 Paper 26.3 엔진에서 데이터팩 로딩, 22종 소환과 체력, 강화 전환, 특수 공격 함수, 보상 테이블 및 처치 후 구역/보스바 정리를 확인합니다. 시험 서버의 네트워크를 끄는 로컬 테스트 도구는 배포 ZIP에 포함되지 않습니다. 실제 클라이언트에서 구조물 탐험, 회피 난이도와 여러 명의 전투 밸런스는 별도 플레이 검증이 필요합니다.

완성된 변환 `pack`을 기준으로 `python ida26/bosses.py`를 실행합니다. 보스판은 `ida26/output/IDA-Vanilla-26.3-Bosses.zip`에 생성됩니다. 안내서는 `python ida26/boss_guide.py`로 갱신합니다.
