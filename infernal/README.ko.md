# Infernal Difficulties — Java 26.3

바닐라 데이터팩만 사용하는 8단계 난이도 구성입니다. 플러그인·모드·리소스팩은 필요 없습니다. 대상은 Java Edition 26.3 정식, 데이터팩 형식 121.0입니다.

공식 버전 안내: https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3

## 설치와 선택

1. 월드를 백업합니다.
2. `output/Infernal-Difficulties-26.3.zip`을 월드의 `datapacks` 폴더에 그대로 넣습니다.
3. 월드를 열거나 `/reload`를 실행합니다.
4. OP 또는 명령 권한으로 다음 중 하나를 실행합니다.

```mcfunction
/function infernal:menu
/function infernal:status
/function infernal:set/peaceful
/function infernal:set/easy
/function infernal:set/normal
/function infernal:set/hard
/function infernal:set/harder
/function infernal:set/insane
/function infernal:set/demon
/function infernal:set/nightmare
```

최초 설치는 현재 바닐라 난이도를 유지합니다. 선택은 월드 전체에 적용되고 재시작·리로드 후 유지됩니다. 클릭 메뉴는 게임 내 플레이어가 실행해야 합니다. 기본 난이도 메뉴에 항목을 추가하지 않습니다. 이 팩 사용 중에는 위 함수로 난이도를 변경하세요. 상위 4단계는 기반 난이도를 Hard로 유지합니다.

## 적용 수치

| 항목 | Harder | Insane | Demon | Nightmare |
|---|---:|---:|---:|---:|
| 일반 몹 최대 체력 | ×1.20 | ×1.40 | ×1.60 | ×2.00 |
| 근접 공격력 속성 | ×1.15 | ×1.30 | ×1.50 | ×1.80 |
| 근접 이동속도 | ×1 | ×1.03 | ×1.05 | ×1.10 |
| 추적 거리 | ×1.10 | ×1.20 | ×1.30 | ×1.50 |
| 추가 방어구 판정 | 10% | 20% | 30% | 50% |
| 방어구 부위 수 | 1 | 1~2 | 2~3 | 2~4 |
| 추가 좀비 무기 판정 | 5% | 10% | 15% | 35% |
| 스켈레톤 계열 강화 활 판정 | 없음 | 10% | 20% | 40% |
| 강화 활 | 없음 | 힘 I | 힘 II | 힘 III |
| 크리퍼 점화 시간 | 30틱 | 30틱 | 25틱 | 20틱 |

배율은 이름공간이 있는 `add_multiplied_total` 속성 보정입니다. Hard 피해 계산, 장비·인챈트가 추가로 작용하므로 최종 피해의 고정 배율을 의미하지 않습니다. 근접 속성은 화살·폭발·물약에 일괄 적용되지 않습니다. 추적 거리 상한은 64블록이며 아기 몹 이동속도는 강화하지 않습니다.

방어구 재질은 Harder 가죽/사슬 각 50%, Insane 사슬 75%/철 25%, Demon 사슬 40%/철 60%, Nightmare 철입니다. Nightmare 가슴 부위 지급 시 5% 확률로 다이아몬드 흉갑을 지급합니다. 각 지급 부위는 Insane부터 40% 확률로 보호 I/II/III를 받습니다. 다이아몬드 흉갑은 보호 II입니다. 각 판정은 방어구 지급에 당첨된 뒤 이루어집니다.

좀비 추가 무기는 Harder 철 삽, Insane 철 검, Demon 날카로움 I 철 검, Nightmare 날카로움 II 철 검입니다. Nightmare 무기 지급 시 5%는 날카로움 II 다이아몬드 검입니다. 추가 지급품의 드롭 확률은 0입니다.

자연 장비를 보존하기 위해 방어구·좀비 무기는 빈 부위에만 지급하며, 강화 활은 기존 인챈트가 없는 기본 활에만 적용합니다. 따라서 실제 추가 지급률은 표의 판정 확률보다 낮을 수 있습니다. 새 난이도를 선택하면 현재 개체의 추가 장비를 복원한 뒤 새 단계로 한 번 다시 판정합니다. 같은 난이도 재선택이나 리로드로 재추첨하지 않습니다.

## 적용 대상

- 근접 보정: 좀비, 허스크, 드라운드, 좀비 주민, 좀비화 피글린, 피글린, 피글린 야수, 위더 스켈레톤, 거미, 동굴거미, 좀벌레, 엔더마이트, 엔더맨, 호글린, 조글린, 변명자, 벡스, 파괴수.
- 체력·추적 보정: 위 근접 대상과 스켈레톤, 스트레이, 보그드, 약탈자, 소환사, 마녀, 크리퍼, 블레이즈, 가스트, 팬텀, 가디언, 셜커, 브리즈, 슬라임, 마그마 큐브. 추적 속성을 지원하는 개체에만 추적 보정이 작동합니다. 슬라임·마그마 큐브의 공격·속도는 기존 크기 규칙을 유지합니다.
- 방어구: 좀비, 허스크, 드라운드, 좀비 주민, 스켈레톤, 스트레이, 보그드.
- Nightmare에서만 드래곤·위더·엘더 가디언 최대 체력 ×1.5. 보스 공격과 패턴은 그대로입니다.
- 워든·주민·동물·골렘·길들인 동물은 제외합니다. 중립 몹의 적대 조건은 유지합니다.

오버월드·네더·엔드의 로딩된 개체를 10틱마다 처리합니다. 차원 추가 팩의 차원은 `scan.mcfunction`에 별도 등록해야 합니다. 몹은 생성 후 최대 약 0.5초 뒤 강화되며, 자연 생성과 스포너·명령 소환을 구분하지 않습니다. 커스텀 몹을 함께 사용하는 경우 소환 시 `infernal.exclude` 태그를 지정해 제외해야 합니다. 기존 보스팩의 일반 몹 기반 커스텀 보스에도 태그가 없으면 보정됩니다.

## 그대로 유지되는 규칙

Peaceful/Easy/Normal/Hard는 원래 규칙을 사용합니다. 상위 단계의 허기·굶주림·회복·수면·주민 감염·좀비 증원·문 파괴·습격은 Hard 규칙입니다. 몹 생성량과 상한, 밝기, AI, 상태이상, 환경 피해, 자원, 거래, 기본 경험치, 사망·하드코어·월드 게임 규칙을 변경하지 않습니다. 별도 스킬·이벤트·아이템·강제 생성은 없습니다.

## 복원과 제거

난이도 변경 시 팩이 추가한 속성 보정을 제거하고 체력 비율을 유지합니다. 추가 장비를 받은 개체는 적용 직전의 전체 장비·드롭 설정으로 복원합니다. 적용 이후 몹이 주운 장비나 다른 팩이 변경한 장비도 이때 이전 상태로 돌아갈 수 있습니다. 이 팩의 장비 보정과 다른 장비 관리 팩은 같은 개체에 함께 사용하지 않는 것을 권장합니다.

`/function infernal:uninstall`은 Hard를 선택하고 로딩된 개체를 복원합니다. **미로딩 청크의 강화 몹은 다음 로딩 때 복원되므로 곧바로 팩을 삭제하면 안 됩니다.** 기존 지역을 로딩해 복원한 뒤 팩을 제거하거나, 백업으로 되돌리세요. 개체별 복원 데이터는 storage에 저장되며 사라진 개체의 기록은 남을 수 있습니다. 완전 제거 후 필요하면 `/data remove storage infernal:backup mobs`로 기록을 삭제할 수 있지만, 남아 있는 개체의 복원 전에 삭제하면 장비를 복원할 수 없습니다.

## 재현과 검증

```powershell
python infernal/build.py
python infernal/verify.py
```

`build.py`는 Python 표준 라이브러리만 사용합니다. `verify.py`는 이 저장소의 Java 25와 공식 26.3 서버 JAR로 독립 테스트 월드를 만듭니다. 배포 ZIP에는 테스트 월드나 서버 프로그램이 들어가지 않습니다. `output/validation.json`과 `validation-console.log`가 실제 검증 결과입니다. 클라이언트 화면과 전투 체감 밸런스는 별도 플레이 테스트가 필요합니다.
