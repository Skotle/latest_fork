# Infernal Difficulties — 단독 Paper 26.3 플러그인

`Peaceful → Easy → Normal → Hard → Harder → Insane → Demon → Nightmare`

JAR 하나로 8단계를 제공합니다. 데이터팩·다른 플러그인·클라이언트 모드·리소스팩은 필요 없습니다. 바닐라 몹 속성, 장비, 인챈트, 크리퍼 점화 시간만 조정합니다. 별도 스킬·이벤트·아이템·추가 AI는 없습니다. Java 25 / Paper 26.3용입니다.

## 설치

1. 서버를 종료합니다.
2. `output/InfernalDifficulties-1.0.0-Paper-26.3.jar` 하나를 서버 `plugins` 폴더에 넣습니다.
3. 서버를 시작합니다. 설정은 `plugins/InfernalDifficulties/config.yml`에 자동 생성됩니다.
4. OP 또는 콘솔에서 기본 `/difficulty` 명령으로 선택합니다.

```mcfunction
/difficulty
/difficulty peaceful
/difficulty easy
/difficulty normal
/difficulty hard
/difficulty harder
/difficulty insane
/difficulty demon
/difficulty nightmare
```

명령어 트리에 8개 리터럴을 등록하므로 자동완성과 `/execute run difficulty nightmare`도 지원합니다. `/difficulty`만 실행하면 선택된 단계를 표시합니다. 권한은 `minecraft.command.difficulty` 또는 `infernal.admin`이며 `infernal.admin`은 기본 OP 전용입니다. `infernal.admin`을 다른 권한에 연결하지 않았으므로 일반 플레이어에게 자동 부여되지 않습니다.

기본 명령 이름 `/difficulty`는 이 플러그인의 8단계 명령으로 등록합니다. `/minecraft:difficulty`는 바닐라 명령으로 남습니다. 상위 단계 선택에는 접두사 없는 `/difficulty`를 사용하세요. 다른 플러그인이 같은 명령을 덮어쓰면 충돌할 수 있습니다.

## 기존 데이터팩에서 전환

기존 Infernal 데이터팩을 설치한 월드라면 **데이터팩과 이 플러그인을 동시에 사용하지 마세요.**

1. 데이터팩이 활성화된 상태에서 `/function infernal:set/hard`를 실행합니다.
2. 기존 강화 몹이 있는 지역을 로딩해 복원합니다. 미로딩 청크의 몹은 그 지역을 방문할 때 복원됩니다.
3. 서버를 종료하고 해당 데이터팩 ZIP을 제거한 뒤 이 플러그인을 설치합니다.

기존 데이터팩의 `inf.active` 태그가 남은 개체는 중첩 강화를 피하기 위해 플러그인이 제외합니다. 데이터팩의 속성·장비 보정은 이 플러그인이 임의로 삭제하지 않습니다. 아직 데이터팩을 설치하지 않았다면 이 전환 절차는 필요 없습니다.

## 난이도 수치

Peaceful/Easy/Normal/Hard는 바닐라 규칙 그대로입니다. 상위 4단계는 실제 월드 난이도를 Hard로 설정한 뒤 아래 보정을 적용합니다.

| 요소 | Harder | Insane | Demon | Nightmare |
|---|---:|---:|---:|---:|
| 일반 적대 몹 최대 체력 | ×1.20 | ×1.40 | ×1.60 | ×2.00 |
| 근접 공격력 속성 | ×1.15 | ×1.30 | ×1.50 | ×1.80 |
| 근접 이동속도 | 기본 | ×1.03 | ×1.05 | ×1.10 |
| 추적 거리 | ×1.10 | ×1.20 | ×1.30 | ×1.50 |
| 추가 방어구 판정 | 10% | 20% | 30% | 50% |
| 방어구 지급 부위 수 | 1 | 1~2 | 2~3 | 2~4 |
| 좀비 추가 무기 판정 | 5% | 10% | 15% | 35% |
| 스켈레톤 계열 강화 활 판정 | 없음 | 10% | 20% | 40% |
| 강화 활 | 없음 | 힘 I | 힘 II | 힘 III |
| 크리퍼 점화 시간 | 30틱 | 30틱 | 25틱 | 20틱 |
| 드래곤·위더·엘더 가디언 체력 | 기본 | 기본 | 기본 | ×1.50 |

속성 배율에 Hard의 기본 피해 계산과 장비·인챈트가 함께 작용합니다. 따라서 표의 공격력은 최종 피해의 고정 배율이 아닙니다. 화살·폭발·물약에는 근접 배율을 적용하지 않습니다. 추적 거리 상한은 64블록이고 아기 몹에는 이동속도 배율을 적용하지 않습니다.

### 장비 세부 규칙

- Harder 방어구: 가죽/사슬 각 50%, 인챈트 없음.
- Insane 방어구: 사슬 75%/철 25%, 지급 부위별 40% 확률로 보호 I.
- Demon 방어구: 사슬 40%/철 60%, 지급 부위별 40% 확률로 보호 II.
- Nightmare 방어구: 철, 지급 부위별 40% 확률로 보호 III. 가슴 부위를 지급할 때 5% 확률로 보호 II 다이아몬드 흉갑.
- 좀비 추가 무기: Harder 철 삽, Insane 철 검, Demon 날카로움 I 철 검, Nightmare 날카로움 II 철 검. Nightmare 무기 지급 시 5%는 날카로움 II 다이아몬드 검.
- 방어구와 좀비 무기는 빈 부위에만 지급합니다. 강화 활은 인챈트가 없는 기존 활만 강화합니다. 자연 장비를 약한 장비로 덮어쓰지 않으므로 실제 지급률은 표의 판정 확률보다 낮을 수 있습니다.
- 추가 지급품은 드롭 확률 0과 사망 드롭 필터를 적용합니다. 경험치는 추가 지급 전 장비를 기준으로 바닐라 보상 분포를 사용합니다.
- 발광·이름 변경·입자·새 텍스처는 없습니다. 지급품에는 복원·드롭 관리용 보이지 않는 소유 메타데이터만 기록합니다.

### 적용 대상

- 근접 보정: 좀비, 허스크, 드라운드, 좀비 주민, 좀비화 피글린, 피글린, 피글린 야수, 위더 스켈레톤, 거미, 동굴거미, 좀벌레, 엔더마이트, 엔더맨, 호글린, 조글린, 변명자, 벡스, 파괴수.
- 체력·추적 보정: 위 대상과 스켈레톤, 스트레이, 보그드, 약탈자, 소환사, 마녀, 크리퍼, 블레이즈, 가스트, 팬텀, 가디언, 셜커, 브리즈, 슬라임, 마그마 큐브. 해당 속성이 없는 몹은 그 속성 보정만 건너뜁니다. 슬라임·마그마 큐브의 공격·속도는 기본 크기 규칙입니다.
- 방어구: 좀비, 허스크, 드라운드, 좀비 주민, 스켈레톤, 스트레이, 보그드.
- 워든, 주민, 일반 동물, 길들인 동물, 아군 골렘은 제외합니다. 중립 몹의 적대 조건은 유지합니다.
- 일반 바닐라 몹을 기반으로 만든 커스텀 몹은 소환 시 `infernal.exclude` 스코어보드 태그를 넣어 제외하세요. 다른 플러그인에서는 `infernaldifficulties:exclude` PDC 바이트를 1로 설정할 수도 있습니다.

## 유지되는 바닐라 규칙

허기·포만감 소모, 음식, 자연 회복, 수면, 낙하·용암·익사 등 환경 피해, 방패·토템, 내구도, 주민 감염·좀비 증원·문 파괴·습격, 자연 생성량과 상한·밝기·스포너, 드롭 테이블, 거래, 광물, 사망·부활·하드코어 및 게임 규칙을 별도 변경하지 않습니다. 상위 4단계의 굶주림은 Hard와 같아 사망할 수 있습니다.

## 저장·복원·다중 월드

최초 설치의 `preset: auto`는 기존 월드별 바닐라 난이도를 보존합니다. `/difficulty <단계>`를 실행하면 **현재 로딩된 모든 월드**와 이후 로딩되는 월드에 같은 단계가 적용됩니다. 커스텀 차원도 해당 World가 로딩되면 처리합니다. 선택은 config.yml에 저장되며 서버 재시작 후 유지됩니다.

생성·청크 로딩 이벤트 다음 틱에 한 번 적용합니다. 지속적인 전체 몹 검색이나 몹 추가 생성은 하지 않습니다. 최초 활성화와 단계 변경 때만 로딩된 몹 전체를 처리합니다. 자연 생성·스포너·명령 소환 모두 같은 대상 규칙입니다.

개체의 PDC에 단계와 장비·점화 시간 복원 정보를 저장하고, 이름공간이 있는 속성 수정자만 추가·제거합니다. 청크 재로딩과 서버 재시작에 중첩되지 않으며 같은 난이도 재선택으로 장비를 다시 추첨하지 않습니다. 단계가 실제 변경되면 이전 장비를 복원한 뒤 새 단계의 확률로 한 번 판정합니다. 체력은 비율을 유지합니다.

장비 복원은 플러그인이 지급한 부위만 처리합니다. 다른 장비로 교체된 부위는 그 장비를 보존합니다. 외부 명령이나 다른 플러그인으로 기반 난이도가 다른 단계로 바뀌면 다음 틱에 그 바닐라 단계를 선택해 강화도 해제합니다. 같은 Hard로 설정하는 것은 월드 난이도 변경이 발생하지 않을 수 있으므로 상위 단계를 해제할 때는 `/difficulty hard`를 사용하세요.

## 제거

먼저 `/difficulty hard`를 실행해 로딩된 몹을 복원하세요. **미로딩 청크의 개체는 다음 로딩 시 복원되므로, 기존 강화 몹이 있는 지역을 방문해 복원하기 전에 JAR을 제거하면 해당 개체의 강화가 남습니다.** 서버 종료만으로는 강화를 제거하지 않습니다. 청크를 모두 방문하기 어렵다면 플러그인을 Hard 상태로 유지하거나 강화 적용 전 월드 백업을 사용하세요.

## 빌드·검증

```powershell
python infernal-paper/build.py
python infernal-paper/verify.py
```

저장소의 Java 25 및 `.tools/paper263/libraries`에 있는 Paper 26.3 API를 사용합니다. 외부 라이브러리를 JAR에 포함하지 않으며 플러그인 런타임 다운로드도 없습니다. `verify.py`는 격리된 Paper 테스트 서버를 두 번 실행해 실제 명령 등록, 권한, 몹 강화·복원과 재시작을 검사합니다. `.tools/paper263-latest/paper.jar`가 있으면 우선 사용하고, 없으면 기존 build 41 서버를 사용합니다. 테스트용 Probe 플러그인은 배포 JAR에 들어가지 않습니다.

최종 배포 JAR은 **2026-10-17 기준 공식 최신 안정 Paper 26.3 build 200**에서 검증했습니다. 이전 build 41에서도 확인했습니다. 정확한 서버 버전, 항목별 결과와 검사한 JAR의 SHA-256은 `output/validation.json`에 기록되어 있습니다.

결과는 `output/validation.json`과 단계별 로그에 기록합니다. 실제 클라이언트 접속 화면·전투 체감은 별도 플레이 테스트 대상입니다. 명령 등록은 Paper의 공식 Lifecycle Commands API를 사용합니다: https://docs.papermc.io/paper/dev/command-api/basics/registration/
