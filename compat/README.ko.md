# MythicMobs 5.13.0 — Paper 26.3 로컬 호환 빌드

결과물: `release/MythicMobs-5.13.0-local263-r1.jar`

공식 신규 릴리스나 전체 소스 재빌드가 아니라, 제공된 5.13.0 바이너리에 적용한 재현 가능한 호환 패치입니다. 원본 JAR는 보존합니다.

## 변경

- `NMSVersion`의 내부 버전 맵에 **26.3.0 → v26_2** 매핑을 추가합니다. 기존 26.2 처리기를 재사용합니다.
- 원본 불변 맵을 복사한 뒤 항목을 추가하고 다시 수정 불가능하게 만듭니다.
- 26.2 등 기존 매핑을 유지합니다. 26.4 등 다른 버전은 추가하지 않습니다.
- 플러그인 버전은 `5.13.0-local263-r1`로 표시합니다.
- 수정 대상은 `NMSVersion.class`, `plugin.yml` 두 항목뿐입니다. 나머지 ZIP 항목 내용은 원본과 같습니다.
- 입력 SHA-256을 검사하여 다른 버전 JAR에 패치를 잘못 적용하지 않도록 합니다.

## 교체

1. 서버를 완전히 종료합니다.
2. 서버 `plugins`의 기존 MythicMobs JAR를 서버 밖에 백업합니다.
3. 수정 JAR 한 개만 `plugins`에 넣습니다. 기존 `plugins/MythicMobs` 설정과 데이터는 유지합니다.
4. 서버를 재시작하고 `MythicMobs v5.13.0 ( build r1 ) has been successfully loaded!`를 확인합니다.

이전 `extreme-plugins.zip`에는 원본 5.13.0 JAR가 있으므로 다시 덮어쓰지 마세요. 이번 `mythic263-update.zip`은 수정 JAR와 이 안내문만 포함합니다.

## 실제 검증

- Paper **26.3-41-main@a15fed9**, Java **25.0.4.1**, Windows 테스트 서버.
- 플러그인 활성화 성공, `getNMS()` null 오류 해소.
- 26.2 기존 매핑 유지, 미지원 26.4 매핑 없음.
- 강화 몬스터 5종 생성 및 Mythic 등록 확인.
- 5종 최대 체력 120/90/100/180/200 적용 확인.
- 5개 고유 REPLACE 규칙 로딩 확인.
- NATURAL 사유로 생성한 좀비가 강화 몬스터로 교체되는 것을 확인.
- 테스트 전용 `SmokeProbe`는 배포물에 포함하지 않습니다.
- 검증 로그: `release/mythic263-smoke.log`.

## 검증 범위와 남은 사항

이 패치는 기존 26.2 NMS 구현을 재사용하므로 모든 MythicMobs 기능의 26.3 호환성을 보증하지 않습니다. 플레이어와의 전투, 고급 패킷/가상 엔티티, 모든 AI/스킬, 다른 플러그인 조합, Linux 실서버는 미검증입니다.

테스트에서는 원본의 기본 팩과 레거시 경로가 같은 자연 출현 파일을 중복 로딩하는 현상도 관찰했습니다. 고유 규칙은 5개지만 내부 등록은 10개였습니다. 따라서 설정의 Chance를 실효 출현 확률로 단정하면 안 됩니다. 이 호환 패치는 해당 로더 동작은 변경하지 않습니다.

기본 예제 대화의 미정의 스킬 경고, 테스트 호스트의 Windows 성능 카운터 경고, 활성 몬스터가 있는 상태에서 종료할 때 비활성 플러그인의 작업 등록 경고가 남았습니다. 활성화 및 위 기능 검사는 통과했습니다.
